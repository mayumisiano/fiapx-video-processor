# ADRs

Architecture Decision Records — one atomic, already-made decision per file. Immutable once accepted; a later change supersedes an old ADR with a new one rather than editing it in place.

Naming: `NNNN-short-title.md` (e.g. `0001-use-text-for-status-columns.md`).

Format:

```markdown
# NNNN. Title

Status: proposed | accepted | superseded by NNNN

## Context

## Decision

## Consequences
```
