# RFCs

Larger design proposals that bundle several related decisions (schema, module layout, API contracts, etc.), written for review before or alongside implementation.

Naming: `NNNN-short-title.md` (e.g. `0001-db-schema-and-go-scaffolding.md`).

If a specific decision inside an RFC is worth tracking independently (e.g. it gets revisited later), extract it into its own file under `docs/adr/`.
